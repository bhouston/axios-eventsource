# Security policy

## Supported versions

Security fixes target the latest published version of axios-eventsource. Upgrade to the latest version before reporting a suspected issue. Older versions do not have a separate maintenance branch.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/bhouston/axios-eventsource/security/advisories/new) to send a confidential report. Include affected versions, reproduction steps, impact, and any suggested mitigation. Please do not post exploit details in a public issue.

If private reporting is unavailable, contact Ben Houston using the contact information on [ben3d.ca](https://ben3d.ca) and request a private reporting channel before sharing sensitive details. Reports are reviewed on a best-effort basis; no response-time guarantee is made.
